# 摄影作品限时查看系统

客户凭卡密访问摄影作品预览，管理端可控制卡密的有效期、使用次数与备注；
封禁后正在浏览的用户会在 5 秒内被请出。全部数据存于 SQLite。

## 快速开始

```bash
npm start          # 启动服务, 默认端口 3000
```

| 入口 | 地址 | 说明 |
|------|------|------|
| 客户端 | http://localhost:3000/ | 输入卡密 → 进入影集 |
| 管理端 | http://localhost:3000/admin | 默认密码 `admin123` |

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `3000` | 监听端口 |
| `ADMIN_PASSWORD` | `admin123` | 管理员密码(生产环境务必修改) |
| `RATE_LIMIT_REDEEM` | `10` | 兑换接口限流(次/10秒/IP) |
| `RATE_LIMIT_LOGIN` | `5` | 登录接口限流(次/10秒/IP) |

## 功能

**客户端**
- 卡密验证(自动格式化 XXXX-XXXX-XXXX)，无效/过期/封禁/次数用尽均有明确提示
- 影集网格 + 灯箱浏览，整页斜向水印(卡密+警示语)，禁用右键
- 每 5 秒心跳校验：封禁/过期/次数耗尽 → 立即全屏遮罩请出，释放已加载图片
- 顶栏实时显示有效期倒计时与在线状态

**管理端**
- 概览：卡密总数/有效/封禁/过期/累计兑换/当前在线，近 14 天兑换趋势图，TOP5 卡密
- 卡密管理：批量生成(数量/次数/有效期/备注，0 次=不限，留空=永久)、封禁、解封、删除
- 访问日志：兑换成功/失败、踢出、生成、封禁等全事件记录，支持按类型过滤与分页
- 数据导出：卡密清单与日志导出 CSV(带 BOM，Excel 直接打开)

## 替换真实作品

示例作品为程序生成的 SVG。替换为真实照片：

```sql
-- 把照片放入 photos/ 目录后, 更新登记(或直接改数据库 data/app.db)
UPDATE photos SET filename='your-photo.jpg', title='作品名' WHERE id=1;
```

作品文件只通过 `/api/photo/:id` 受鉴权输出，无公开直链。


27 项端到端断言：登录鉴权、生成、兑换、心跳踢出、封禁/解封、次数上限、
过期拦截、日志、统计、导出、页面可达性。

## 技术栈与结构

Express + better-sqlite3(WAL)，零构建原生前端。

```
server.js      全部路由(客户端 API + 管理端 API)
db.js          SQLite 模式与预编译语句
public/        index.html(验证) gallery.html(影集) admin.html(后台)
photos/        受保护作品文件
data/app.db    SQLite 数据库(自动创建)
```

## 安全说明

- 卡密 12 位随机(去除易混淆字符)，兑换与登录接口均有限流
- 会话 token 为随机 UUID，心跳服务端校验，封禁即失效
- 管理员 token 存内存(12 小时)，重启后需重新登录
- 所有 SQL 均预编译参数化；前端输出经转义防 XSS
